# Nightshift

Nightshift supports the owner's routine of preparing software work during available hours and having it carried out autonomously at night.

## Language

**Nightshift**:
The desktop application the owner uses to turn software ideas into working software through autonomous work.

**Issue**:
A recorded piece of work in the supplied GitHub repository's issue tracker, developed by the owner during their available hours.

**Nightly job**:
A scheduled period of autonomous work intended to build software from the issues the owner has prepared.

**Parent issue**:
An issue describing a broader goal that is broken into smaller child issues.

**Child issue**:
An issue describing a smaller part of a parent issue's goal. The parent supplies the broader context for that work.

**Dependency**:
An explicitly marked relationship identifying prerequisite work that must be completed before another issue can begin. A parent/child relationship alone does not imply a dependency.

**Ready for agent**:
An issue marked with the `ready-for-agent` label, making it eligible for autonomous nightly work.

**Fresh review**:
An AI review of the change in a new chat that does not inherit the implementation conversation or earlier review conversations.
